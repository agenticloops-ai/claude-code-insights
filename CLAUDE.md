# CLAUDE.md

Research repo that captures and diffs what `@anthropic-ai/claude-code` sends on the wire — system prompt, tool catalog, deferred tools, skills, injected `<system-reminder>` blocks — pinned per release. Captures come from an AgentLens MITM proxy running inside a Docker sandbox; everything is committed as plain text so any two releases are one `git diff` apart.

The full project narrative is in [README.md](README.md). This file is the working brief — what to know to make changes here.

## Layout

```
versions/<YYYY-MM-DD>_<semver>/   captured artifacts, one folder per release
  ├── system-prompt.md             scrubbed prompt for the 02-bare baseline
  ├── tools.json, deferred-tools.json, skills.json
  ├── user-prompt.md               injected <system-reminder> blocks
  ├── stats.md, manifest.json, release-notes.md
  ├── diff-from-<earlier>.md       generated by scripts/diff-versions.py
  └── scenarios/<NN>-<name>/raw/   raw AgentLens session JSON + per-turn split
scenarios/<NN>-<name>/             prompt.txt + meta.json (the probe definition)
sandbox/                            Dockerfile, entrypoint, run.sh, fixtures (MCP, skills)
scripts/                            capture / extract / summarize / diff / release-notes
tools/                              CLI (cci) + web app for browsing captures
.claude/skills/                     /process-version, /extract-capture, /diff-versions
VERSIONS.md                         generated index of every npm release
```

`02-bare` is the **baseline scenario** — its extracted artifacts get promoted to the version root. The other scenarios (`03-with-mcp`, `04-with-skill`, `01-cli-help`) live only under `scenarios/<NN>/` inside the version folder.

## The pipeline

The LLM owns orchestration via slash commands; the bash/Python scripts are thin primitives.

- `/process-version <version> [--diff-from <prev>]` — end-to-end: enable any new opt-in flags, capture every scenario, extract, summarize, fetch release notes, diff. Idempotent.
- `/extract-capture <scenario-dir-or-version-dir>` — turn raw AgentLens JSON into version-comparable artifacts.
- `/diff-versions <from> <to>` — write `versions/<to>/diff-from-<from>.md`.
- `/refresh-versions` — regenerate VERSIONS.md from npm + upstream CHANGELOG.

Direct primitives:

```bash
scripts/capture-version.sh <version>                    # all scenarios
scripts/run-scenario.sh    <version> <scenario>         # one scenario
python3 scripts/extract.py            versions/<dir>/scenarios/<scenario>
python3 scripts/summarize-version.py  <version>
python3 scripts/fetch-release-notes.py <version>
python3 scripts/diff-versions.py      <from> <to>
```

## Working rules

- **Never edit `versions/<v>/` artifacts by hand.** They are derived from `scenarios/<s>/raw/` by `scripts/extract.py`. To fix output, change the extractor (or the raw capture) and re-run extract — don't patch the generated file.
- **Re-extract, don't recapture, when only extraction logic changes.** Recapture (which invokes the real Claude API in Docker) is expensive and non-deterministic; only redo it when the sandbox or fixtures changed.
- **Sandbox isolation is load-bearing.** Captures must not bleed in host `~/.claude`, host MCP, or host git state. The `cch-auth` Docker volume keeps only OAuth credentials and the mitmproxy CA between runs. If you touch `sandbox/`, preserve that boundary.
- **Scrubbing is intentional.** UUIDs, timestamps, cache-busters, the user email, etc. are stripped during extract so artifacts diff cleanly across runs. Don't add scrubbers that hide *real* version-to-version differences (we removed an MCP/tool-name scrubber for this reason — see commit `c0a78595`).
- **Older versions skip, not fail.** Scenarios with `min_version` in `meta.json` exit 125 below that floor; treat exit 125 as "skipped" everywhere downstream (manifest, summarize, diff).
- **Diff template is fixed.** `diff-from-<earlier>.md` always follows: metric table → `## tools` → `## skills` → `## system prompt` → `## user prompt` → `## cli: 01-cli-help`. Missing section = nothing changed at that surface.

## Commit style

Short imperative subject, no scope prefix. Examples from history: `Recapture 2.1.14–2.1.16 (verify scrubber removal)`, `Remove MCP/tool-name scrubber; trust sandbox isolation`, `README: lead with browsing paths, collapse pipeline details`. Keep bodies brief; the *why* matters more than the *what*.

## Requirements

Docker, Python 3, a Claude subscription logged in once via `sandbox/login.sh <version>`.
